# Backup deck (7 slides max)

1. **FlameCheck.** Fire-safety answers from NASA's microgravity fire tests. Team Deep Dish Orbit (Maneesh Reddy, Sravya Rachakonda), NASA Space Apps Chicago 2026, challenge: Flame in Freefall.
2. **The problem.** A Moon base will likely run at ≥30% O₂ and ≤70.3 kPa (10.2 psi). NASA PSI has fire tests at 0 g and 1 g, none at lunar gravity. Engineers need to know what was tested and what wasn't.
3. **The solution.** Ask in plain English and get a short answer, the closest NASA tests ranked, a trust badge, links to each PSI page, and an honest "no direct data" when NASA never tested it. (Screenshot: cotton on the Moon answer.)
4. **Demo.** Ask page → cited answer → citation chip → Moon question → Explore coverage map with the empty Moon-base box.
5. **How it stays honest.** retrieve → answer (GPT-5.6-luna on Azure OpenAI, evidence only) → **verify** → answer or no direct data. Unknown citations, numbers not in the cited row, and Moon claims not stated as 0 g / 1 g bounds are dropped. Gaps are computed from the data.
6. **Tech stack.** 423 NASA test rows and 20/20 on our test set, next to four cards: Microsoft Azure (Azure OpenAI GPT-5.6-luna, App Service for the Python API, Static Web Apps for the site, managed identity so no keys are stored); web app (Next.js 16, React, TypeScript, Tailwind, shadcn/ui, three.js, Recharts); API and AI (Python 3.11, FastAPI, Pydantic, rule-based retrieval, our verifier, Gemini embeddings for text search); data and quality (NASA PSI BASS-II/SAFFIRE/FLEX, 9 NTRS abstracts, pytest, 20-question eval, GitHub, built with Claude Code). The model comparison lives in README.md and eval/results_*.md.
