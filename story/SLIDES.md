# Backup deck (7 slides max)

1. **FlameCheck.** Fire-safety answers from NASA's microgravity fire tests. Team, Chicago, Flame in Freefall.
2. **The problem.** A Moon base will likely run at ≥30% O₂ and ≤70.3 kPa (10.2 psi). NASA PSI has fire tests at 0 g and 1 g, none at lunar gravity. Engineers need to know what was tested and what wasn't.
3. **The solution.** Ask in plain English and get a short answer, the closest NASA tests ranked, a trust badge, links to each PSI page, and an honest "no direct data" when NASA never tested it. (Screenshot: cotton on the Moon answer.)
4. **Demo.** Ask page → cited answer → citation chip → Moon question → Explore coverage map with the empty Moon-base box.
5. **How it stays honest.** retrieve → answer (Gemini, evidence only) → **verify** → answer or no direct data. Unknown citations, numbers not in the cited row, and Moon claims not stated as 0 g / 1 g bounds are dropped. Gaps are computed from the data.
6. **Results.** 423 NASA test rows from BASS-II, SAFFIRE-II/III and FLEX, plus 9 NTRS abstracts. Test set: 20 questions, first run 17/20, now 20/20 with Gemini drafting; the verifier removed 6 drafted claims the data didn't back (e.g. "FLEX-21 burned" when NASA recorded a disruption). Every raw table checked byte for byte against the PSI page.
7. **Team and next steps.** Add ACME CFI-G (up to 85% O₂) for high-oxygen coverage; partial-gravity data as soon as NASA flies it.
